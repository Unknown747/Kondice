- Target Win Chance: CURRENT_CHANCE
- Condition: 'Roll Over' or 'Roll Under' (Dynamically match the required payout target based on CURRENT_CHANCE)

[3. CORE EXECUTION ENGINE]
Execute dice rolls continuously. On each engine tick, fetch the server response asynchronously, parse the outcome ('win' or 'lose'), and evaluate the following state machines instantly.

[4. STATE MACHINE: ON WIN]

- RESET CURRENT_BET       = BASE_BET
- RESET CURRENT_CHANCE    = BASE_CHANCE

3. ASYMMETRIC STAKE MODULATION (Modulo 3 Rule):
   IF (STREAK_LOSS % 3 == 0) THEN:
       // Apply geometric multiplier to recover accrued IDR deficit

   ENDIF

       Force-reset CURRENT_CHANCE = BASE_CHANCE

   NET_PROFIT = Current_Available_Balance - INITIAL_BALANCE
